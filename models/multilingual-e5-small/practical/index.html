Practical — search ten documents in five languages with one query

This is what a business ships: a support-knowledge-base search that doesn't care which language the customer types in. Below is a small mixed-language document set (a mini FAQ). Type a query — English, French, Japanese, Arabic, anything — and the documents are ranked by real embedding similarity, live. No keyword matching, no translation step, no server.
