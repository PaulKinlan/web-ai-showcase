Multilingual E5 — one meaning space for 100 languages

Most search matches words. This model matches meaning — across languages. multilingual-e5-small turns any text from 100 languages into a 384-number vector placed in a single shared space, so "Bonjour le monde" lands next to "Hello world" and a Hindi question can retrieve its Spanish answer. Type below and watch the real cosine similarities come back from a model running entirely on your device.

Honest note: this runs Xenova/multilingual-e5-small, the ONNX q8 export of intfloat/multilingual-e5-small (XLM-RoBERTa base, ~118M params, MIT). E5 models expect a query: or passage: prefix on every input — the demo adds them for you, exactly as the model card prescribes.

Why it matters

A shared multilingual embedding space collapses "translate, then search" into one step — and it runs offline on the device, so private text never has to leave.

  • Cross-lingual search & RAG — one index serves every language; a Portuguese question retrieves a Japanese document.
  • Duplicate & FAQ matching — cluster support tickets by meaning regardless of the customer's language.
  • Semantic dedup & clustering — near-duplicate detection for knowledge bases, news aggregation, moderation queues.
  • On-device privacy — embeddings of sensitive text (mail, notes, health) computed locally; only vectors ever leave.

How the API works

Embeddings are one pipeline call — remember the E5 prefixes:

import { pipeline } from "@huggingface/transformers";

const embed = await pipeline("feature-extraction", "Xenova/multilingual-e5-small");
const out = await embed(
  ["query: Comment faire une omelette ?", "passage: How to cook an omelette"],
  { pooling: "mean", normalize: true },
);
// out.dims → [2, 384]; out[0].data → Float32Array(384), L2-normalised
// cosine similarity = dot(out[0].data, out[1].data) ≈ 0.9

pooling: "mean" averages token vectors into one sentence vector and normalize: true unit-lengths it, so a plain dot product is the cosine similarity. The query:/passage: prefixes come from the model card — E5 was trained with them and scores measurably worse without. Everything runs in a Web Worker so typing stays smooth.
