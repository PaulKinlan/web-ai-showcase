Line, column, bubble

Japanese is written three ways in the wild: horizontal lines (modern print), vertical columns (manga, novels, newspapers), and stacked lines inside a speech bubble. Manga OCR reads all three with the same single model — no mode switch, no line splitting. Load it once, then read each sample and watch the decoder's confidence on every character.

Three reading challenges

Horizontal line

Modern print reads left-to-right, top-to-bottom — the easy case.

Vertical column

Manga and novels stack characters top-to-bottom — the model re-orders them into reading order.

Whole bubble at once

A speech bubble is several lines — the model reads it in one pass, no line segmentation.

Under each result: one chip per decoded character with the model's probability at that step (amber border = below 60%, worth a second look). The vertical and bubble samples prove the two things a generic OCR gets wrong about manga: reading direction and line grouping.
