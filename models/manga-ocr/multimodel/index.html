multi-model composition · manga-ocr → m2m100 · both WASM

Read the bubble, then translate it

The obvious composition for this model: Manga OCR turns pixels into Japanese text, then M2M100 (418M, q8) translates that text to English. Both run on-device in separate workers. The recognised Japanese sits in an editable box between them — fix any misread character before translating, because translation quality depends entirely on the OCR being right.

Step 1 · Manga OCR (image → Japanese)

Step 2 · M2M100 (Japanese → English)

Why this composition is honest

  • No silent pipeline: the OCR output is shown and editable before translation — errors are yours to fix, not buried.
  • Independent lifecycles: each model has its own loader, its own worker, and its own release button; releasing one never disturbs the other.
  • Real timings: both steps report measured wall-clock time on your device, never claimed numbers.
  • Where it breaks: OCR garbage in → translation garbage out. A low-confidence read (amber characters) usually produces a nonsense translation — that is the model telling the truth, not a bug.
