Manga OCR — Japanese text recognition

Upload, paste or drop an image with Japanese text — a manga panel, a sign, a menu, a printout — and the model transcribes it, character by character, on your device. It reads horizontal and vertical writing, furigana, stylised fonts and whole speech bubbles in one pass. Everything runs locally: the image never leaves the tab.

Why it matters

Japanese text on the web is locked inside images: manga and webtoons, restaurant menus, station signage, product packaging, scanned documents. Cloud OCR means uploading someone else's page or your personal documents; this runs the whole recogniser on-device, so the image never leaves the tab — and it keeps working offline.

  • Translation tooling — transcribe a speech bubble, feed the text to a local translator (see the multi-model demo).
  • Reading aids — learners can point at any printed Japanese and get selectable, look-up-able text (furigana and vertical writing included).
  • Accessibility — turn Japanese text baked into images into real, screen-reader-able text.
  • Archiving & search — digitise printed Japanese material without sending it to a third party.

Honest limits: it's a printed-text recogniser trained on manga-style renderings — handwriting, heavy stylisation, very low resolution and mostly-Latin text defeat it, and it can confuse similar characters (ソ/ン, グ/ゲ). On the author's own adversarial test suite this exact browser build (uint8 encoder, q8 decoder, greedy) matches the reference output on 6/12 images byte-for-byte, is off only by half/full-width punctuation on 3 more, and makes real character errors on 3 — the per-character probabilities above are there precisely so you can see when to distrust it.

Use cases

  • Basics — line, column, bubble
    The fundamental skill: horizontal lines, vertical columns and whole speech bubbles, with the model's confidence visible.
  • Practical — panel transcript sheet
    A comic-lettering workflow: crop several regions, transcribe them in batch, copy one clean transcript.
  • Wild — Japanese text radar
    Point your camera at Japanese text in the real world and watch it get read live, frame after frame.
  • Multi-model — manga translator
    Chain Manga OCR → M2M100 translation: a speech bubble goes in, English comes out, all on-device.

How the API works

The export is a standard VisionEncoderDecoderModel (encoder + decoder ONNX), but two verified quirks mean we drive it with ONNX Runtime Web directly instead of the pipeline("image-to-text") shortcut:

  1. It ships no decoder_model_merged_*.onnx, which Transformers.js requires for vision-to-seq models.
  2. Its decoder graph has no KV-cache inputs, and Transformers.js's generate() suppresses the leading [CLS] this model naturally emits — derailing the first token (measured, then confirmed against the author's test suite).
// what this page actually runs (in a Web Worker):
const enc = await ort.InferenceSession.create(encoderBytes);  // uint8, 87 MB
const dec = await ort.InferenceSession.create(decoderBytes);  // int8, 30 MB
const pixel = await vitProcessor(await RawImage.fromURL(url).grayscale().rgb());
const hidden = (await enc.run({ pixel_values: pixel })).last_hidden_state;
const ids = [2];                       // [CLS] — decoder_start_token_id
while (ids.length < max) {
  const { logits } = await dec.run({ input_ids: tensor(ids), encoder_hidden_states: hidden });
  const next = argmax(logits.at(-1));  // greedy, one Japanese character per step
  if (next === 3) break;               // [SEP]
  ids.push(next);
}
const text = ids.map((i) => vocab[i]).join(""); // char-level detokeniser (vocab.txt)

Decoding is greedy and cacheless (each step re-decodes the growing sequence — cheap for a 2-layer decoder). The image is grayscaled and resized to 224×224 exactly like the reference pipeline; the detokeniser is the base repo's vocab.txt (input is pixels, so the training-time MeCab word-tokeniser is never needed).
