Practical: editorial triage queue

A magazine desk, a forum, or a coursework inbox gets a stream of submissions. Run each through the authenticity pre-check on-device and badge the ones that read machine-written so a human reviews them first — a routing signal, never an accusation. Slide the threshold to trade sensitivity for precision, and watch the queue re-triage instantly. Nothing is uploaded: the drafts never leave this tab.

Read this as routing, not a verdict

The right product move is to route, not to punish: a badge that says “a human should read this one first”. A polished human press release can read machine-smooth; a careful human drafter can be flagged; modern chat-model text can slip under a GPT-2-era detector entirely. Keep the human in the loop, keep the threshold conservative, and never present the badge as proof — OpenAI's own model card says the same. Because scoring happens locally, you can run it on unreleased drafts and private messages you would never send to a cloud API.
