Protein mutation oracle

A protein language model reads sequences the way an LLM reads text — but its "words" are the 20 amino acids. Mask a position and ESM-2 predicts which residue belongs there; from that same prediction it scores every possible mutation as tolerated or likely-damaging. This is the zero-shot method behind modern variant-effect prediction, running entirely in your browser.

Why it matters

Trained only to fill in masked residues across tens of millions of natural proteins, ESM-2 learns which amino acids are compatible with a protein's structure and function. That single skill powers a surprising amount of biology — without any labels, structures, or experiments:

  • Variant-effect prediction — a mutation the model finds far less likely than the wild-type residue is a candidate for being damaging. The sickle-cell mutation in hemoglobin (E6V) scores strongly negative here.
  • Protein design — the per-position predictions suggest substitutions the model considers plausible.
  • Conservation at a glance — how peaked the distribution is shows how constrained a position is.
  • Teaching — see a language model "understand" protein grammar, interactively, with no server.

This is a fast, zero-shot signal, not a clinical verdict. The score is the model's sequence likelihood — it has no knowledge of a specific structure, assay, or patient, and the 35M model is the smallest ESM-2 (larger models are more accurate). Use it to explore and prioritise, not to diagnose.

How the API works

The fill-mask pipeline needs a mask_token this ONNX build omits, so we run the model directly and read the logits at the masked position:

import { AutoTokenizer, AutoModelForMaskedLM, Tensor }
  from "@huggingface/transformers";

const tok = await AutoTokenizer.from_pretrained("Xenova/esm2_t12_35M_UR50D");
const model = await AutoModelForMaskedLM.from_pretrained(
  "Xenova/esm2_t12_35M_UR50D", { dtype: "q8" });

const ids = Array.from((await tok(sequence)).input_ids.data).map(Number);
ids[pos + 1] = maskId;                       // +1 for the leading <cls>
const { logits } = await model({ input_ids: new Tensor("int64", …) });
// softmax the logits row → P(amino acid) at that position;
// ln P(mutant) − ln P(wild-type) = the variant-effect score.

Each click is one forward pass, run in a Web Worker so the page stays responsive.
