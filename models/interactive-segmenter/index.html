MagicTouch — point at it, select it

Google's recommended MagicTouch model turns one normalized image coordinate into a foreground probability for every pixel. It is a MobileNetV3-like convolutional network with a custom decoder, optimized for browser and mobile use. The pinned float32 model, inference, tensor reduction, and dense compositing all stay on your device.

Why it matters

A point is a much lighter prompt than drawing a polygon. That makes precise object selection available to private photo editors, annotation tools, visual accessibility workflows, and creative effects without a server round-trip.

  • Private editing: cut a subject out without uploading the photo.
  • Fast annotation: turn one click into a dense training mask.
  • Object-aware effects: keep, recolour, blur, or measure only the selected region.
  • Honest limits: the model card warns about small/distant objects, thin features, close objects merging, and non-consensual human segmentation.

How the API works

const segmenter = await InteractiveSegmenter.createFromOptions(vision, {
  baseOptions: { modelAssetBuffer: verifiedMagicTouchBytes, delegate: "CPU" },
  outputCategoryMask: true,
  outputConfidenceMasks: true,
});
const result = segmenter.segment(imageBitmap, {
  keypoint: { x: 0.50, y: 0.50 }, // normalized coordinates
});
const foreground = result.confidenceMasks[1].getAsFloat32Array();

This implementation fetches the exact numbered artifact only after consent, checks its SHA-256 before creating the task, keeps one verified Cache Storage copy, and uses the shared loader for current/partial/clear/retry lifecycle. It transfers the image bitmap into a dedicated worker and returns a transferred RGBA composite.
