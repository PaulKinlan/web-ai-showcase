all-mpnet-base-v2 — the reference-quality sentence embedding

all-mpnet-base-v2 is the model sentence-transformers points at when you ask for “best quality”. It fine-tunes Microsoft’s MPNet — which pre-trains with a permutation objective that blends masked and autoregressive language modelling — over a billion paired sentences, and turns each sentence into a 768-number point in meaning space. No query prefix is required: questions and documents use the same mean-pooling recipe. Build a live similarity matrix, search by meaning, and inspect the real vector geometry. Nothing leaves your device.

See inside — the vector, and why the model choice matters

The encoder emits one 768-number vector per token. To get a single vector per sentence, all-mpnet-base-v2 mean-pools those token vectors (mask-aware) and L2-normalizes, so every sentence becomes a unit-length arrow and cosine similarity is a plain dot product. Pick a sentence to see its real vector and its pre-normalization magnitude.

Why it matters

Embeddings are the quiet workhorse behind search, recommendations, deduplication, clustering, and retrieval-augmented generation. all-mpnet-base-v2 is the long-standing quality leader on the sentence-transformers leaderboards — a 768-dimensional representation whose geometry separates meaning sharply (genuinely related sentences score high while unrelated ones land near zero, not bunched together). When you want the strongest all-purpose English sentence vector and can spare a ~105 MB download, this is the one to reach for.

  • Semantic search — rank a corpus by meaning, not keyword overlap, entirely client-side.
  • Nearest-label classification — embed your labels once, then tag new text by closest label with zero training.
  • Clustering & dedup — group "same thing, different words" and collapse near-duplicates.
  • Private RAG retrieval — fetch the right snippet to feed a local LLM, all on-device.

How the API works

Feature-extraction plus the pooling discipline is the whole recipe — and note there is no prefix:

import { pipeline } from "@huggingface/transformers";

const extract = await pipeline(
  "feature-extraction",
  "Xenova/all-mpnet-base-v2",
  { dtype: "q8" }, // downloads + caches ~105 MB once
);

// MPNet uses MEAN pooling and needs NO instruction prefix — embed query and doc identically:
const out = await extract(["how do I sign in?", "the login page rejects my password"], {
  pooling: "mean",
  normalize: true,
});
const [q, d] = out.tolist();

// unit-length vectors → cosine similarity is just the dot product:
const sim = q.reduce((s, x, i) => s + x * d[i], 0); // high — same meaning

This page loads the browser-ready Xenova/all-mpnet-base-v2 ONNX export (an exact export of sentence-transformers/all-mpnet-base-v2) pinned to a fixed revision, and asks the worker for the un-normalized pooled vectors so “See inside” can show the real pre-normalization magnitude, then normalizes them in JS. Inference runs in a Web Worker, so the matrix, projection and comparison never jank the page.
