MobileNetV4 — the 2024 backbone built to run anywhere

Same 1,000-way ImageNet job as the ViT and ConvNeXt demos, but with the newest mobile-first design. MobileNetV4-Conv-Small is a 3.8M-parameter universal inverted bottleneck (UIB) network — one block family that spans classic inverted residuals through attention — tuned by neural architecture search for real hardware. Classify an image and read the real millisecond latency; the story here is one architecture, every device.

Why fp32 and not q8?

This repo prefers 8-bit weights, but the canonical q8 conversion failed semantic sanity in the exact browser probe: a rights-cleared dog fixture (Wikimedia Commons, CC-BY-4.0) came back as greenhouse / cello / ocarina, and a citrus still-life as knee pad. The canonical fp32 graph classified the same images as Brittany spaniel (79.9%) and lemon (60.0%). fp32 is therefore the honest choice and is still only ~15 MB.

Why it matters

MobileNetV4 is the latest step in the on-device vision lineage: a single universal inverted bottleneck design that the authors show scales from microcontrollers and phones to servers, with accuracy that rivals models several times its size. When the constraint is battery, bandwidth, or latency — not the last point of accuracy — this is the modern backbone you reach for.

  • Real-time camera tagging — classify a live webcam feed frame-by-frame; MobileNetV4 is fast enough to keep up.
  • Instant, offline categorisation — a ~15 MB download tags images the moment they're picked, with no server round-trip.
  • Cheap prefilter — run MobileNetV4 first to triage, and only escalate the hard/uncertain cases to a heavier model like ViT (see the multi-model demo).
  • Low-power edge devices — the small footprint fits constrained hardware where a transformer wouldn't.

How the API works

The convenience path is two lines with Transformers.js:

import { pipeline } from "@huggingface/transformers";

const classify = await pipeline(
  "image-classification",
  "onnx-community/mobilenetv4_conv_small.e2400_r224_in1k",
  { dtype: "fp32" },
); // downloads + caches ~15 MB once

const output = await classify(imageURL, { top_k: 5 });
// → [{ label: "Brittany spaniel", score: 0.80 }, { label: "Welsh springer spaniel", score: 0.04 }, …]

This page goes one level deeper for "See inside": instead of the pipeline it runs the model's own processor then model() in a single forward pass, so it can read the raw logits tensor (all 1,000 ImageNet classes) and compute the softmax, entropy, and margin itself. Inference runs in a Web Worker so the page remains responsive.
