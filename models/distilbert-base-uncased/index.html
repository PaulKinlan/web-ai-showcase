DistilBERT — the small, fast BERT that predicts the missing word

DistilBERT is BERT, distilled: a student model trained to mimic BERT-base that keeps ~97% of its language understanding at 40% of the size and ~60% of the latency — the canonical lightweight encoder. Its one job here is masked language modelling: hide a word behind [MASK] and it ranks what belongs there. Type a sentence with a mask and see its guesses, plus the exact logits it computed. Everything runs on your device.

See inside — logits, not just a guess

A language model doesn't output words — it outputs a logit (a raw, unbounded score) for every one of its 30,522 vocabulary tokens at the masked position. We softmax those into probabilities. The bars above show the probability; the logit beside each is the actual number the network produced. Watch how a confident prediction ("Paris") sits far above the pack in logit space, while an ambiguous slot spreads the mass out. Why it matters

DistilBERT is the reference small English encoder: cheap enough to run interactively on any device, yet its masked-word distribution is a usable probability model of English. Because it scores every word in context, you can ask it what fits, how strongly, and compare alternatives — all locally, with no prompt engineering and no API bill.

  • Offline autocomplete — suggest the next or missing word in a compose box, with real probabilities.
  • Cloze & vocabulary drills — generate fill-in-the-blank exercises with graded difficulty from the entropy.
  • Word-choice comparison — score candidate words at a slot (tone, register, formality) using the logits.
  • A teaching surface — the exact logits make “how a language model decides” legible without the maths.

How the API works

The one-liner uses the fill-mask pipeline:

import { pipeline } from "@huggingface/transformers";

const unmask = await pipeline("fill-mask", "Xenova/distilbert-base-uncased");
const out = await unmask("The capital of France is [MASK].");
// → [{ token_str: "paris", score: 0.10, sequence: "…" }, { token_str: "nantes", … }]

For the "see inside" surface we go one level lower — AutoModelForMaskedLM — so we can read the exact logits tensor ([1, sequence, 30522]), slice the row at the [MASK] position, and softmax it ourselves. That's the only way to show the real logit values, not just the pipeline's rounded scores. All of it runs in a Web Worker so the page never janks.
