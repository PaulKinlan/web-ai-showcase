OPUS-MT Dutch → English — one small model, one direction

The multilingual demos (M2M100, NLLB-200) cover every language with one big model. Helsinki-NLP's OPUS-MT family takes the opposite bet: a dedicated bilingual model per pair. This is the Dutch → English member — ~115 MB, quick to load, and trained on the real OPUS Dutch–English parallel corpus. Type Dutch, watch the English stream in, all on-device.

Why it matters

Dutch is a top-20 web language, and a huge share of Dutch content — government portals, news, support docs, reviews — never gets translated because server translation costs money and leaks data. A dedicated 115 MB pair model makes Dutch → English a client-side feature: no API key, no upload, works offline after one download.

  • Read the Dutch web — translate nieuws, overheidsites, and forums in-place without sending text away.
  • Customer-feedback triage — batch-translate Dutch reviews or tickets to English for an international team, on-device.
  • Localisation assist — pre-translate Dutch UI strings and let a human review the drafts.
  • Privacy-first pipelines — chain after Dutch ASR (already in this showcase) for fully local Dutch speech → English text.

How the API works

The pair is its own model; the pipeline call needs no language codes:

import { pipeline } from "@huggingface/transformers";

const translate = await pipeline(
  "translation",
  "Xenova/opus-mt-nl-en",
); // downloads + caches ~115 MB once — this pair only

const out = await translate("Hoi, hoe gaat het met je?");
// → [{ translation_text: "Hi, how are you?" }]

There's no src_lang/tgt_lang — the direction is baked into the weights. This page streams output chunks via a TextStreamer inside a Web Worker so the UI stays responsive, and the shared model loader auto-initialises the model from cache on return visits.
