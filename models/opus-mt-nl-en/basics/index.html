Basics: translate a Dutch phrase

The simplest thing the model does: take a Dutch sentence and render it in English. Type a phrase (or tap a sample), translate, and watch the English appear chunk by chunk. The whole run happens in this tab — the ~115 MB model downloads once, then it's instant and offline.

There's no language code to set — the direction is the model. That's the OPUS-MT trade: swap one big multilingual model for a small dedicated pair, and only ship the direction you need. The stream arrives in word-sized chunks (the streamer flushes at whitespace boundaries).
