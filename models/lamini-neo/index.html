LaMini-Neo — instructions in, answers out, 125M parameters

LaMini-Neo-125M is a tiny GPT-Neo that MBZUAI fine-tuned on 2.6 million instruction-response pairs. It follows simple instructions — explain, summarize, rewrite, draft — with a fraction of the weights of a modern chat model, and it runs on a plain CPU in your browser.

Why it matters

      

        Most instruction models need billions of parameters. LaMini shows that 125M parameters tuned on
        good instruction data can follow simple requests — which makes private, offline instruction
        following feasible on phones and low-end devices.
      

      
    
        
  • On-device helper text — summarize, reword, or explain snippets with zero uploads.
    • 
        
  • A teaching model — see instruction tuning at its smallest: the same template and sampling controls as big models, at 140 MB.
    • 
        
  • Baseline for the family — the smallest GPT-Neo/LaMini rung; compare against the bigger models on the showcase.
    • 
        
  • Privacy-by-construction drafting — notes, emails, and ideas reworded locally.

How the API works

      
The friendly one-liner is the text-generation pipeline:

      
import { pipeline } from "@huggingface/transformers";

const gen = await pipeline("text-generation", "Xenova/LaMini-Neo-125M", { dtype: "int8" });
const prompt = "### Instruction:\\nExplain photosynthesis simply.\\n\\n### Response:\\n";
const out = await gen(prompt, { max_new_tokens: 96, do_sample: true, temperature: 0.7 });
// out[0].generated_text → the response after the ### Response: marker

      

        The demo streams tokens through a TextStreamer inside a Web Worker, so the page never
        blocks — the token chain is the stream, one real token at a time.
