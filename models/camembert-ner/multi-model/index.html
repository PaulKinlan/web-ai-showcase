NER finds the names, fill-mask reimagines them

The wild page let you recast the names. Here a second model does it. The French NER model locates every entity of the type you choose; then CamemBERT fill-mask — the same base architecture, the same language — masks each name in turn and predicts a replacement that fits the context. Chain them and a sentence recasts itself, staying grammatical because each model does one job well. Both run locally.

How the chain works

  1. NER (French CamemBERT, token-classification) finds every entity span matching your chosen type, with exact character offsets.
  2. For each span we build a copy of the sentence with that name replaced by [MASK].
  3. Fill-mask (CamemBERT-base) predicts the most likely word for the mask in context; we take the top prediction that isn't the original name.
  4. We stitch the predictions back in at the exact spans. Because fill-mask respects grammar and context, the sentence stays coherent — just recast.
