Index the names, or make them disappear

Two things you can ship the moment you know where every name sits. Entity index: scan a whole document and collect who, which organisations and which places it mentions, with mention counts — then copy the result as JSON for a pipeline. Privacy redaction: the same spans are exactly what you'd mask before sharing a document. Both run on-device, so the sensitive text never leaves the tab.
