MobileBERT — the tiny judge

Natural-language inference asks: given a premise, does a hypothesis follow (entailment), contradict it, or stay neutral? MobileBERT is Google's mobile-optimized BERT — a bottleneck architecture that keeps BERT-base's quality at a fraction of the size. This MNLI fine-tune answers with real probabilities, on-device, in 25 megabytes.

Why it matters

NLI is the workhorse of consistency checking: does a summary match the source, does an answer follow from the evidence, does a claim contradict known facts? MobileBERT makes that judgment fast enough and small enough for on-device, real-time use.

  • Claim & answer validation — check a generated answer against its source.
  • Summary fidelity — flag when a summary contradicts the original text.
  • Content moderation — detect contradictions in user-supplied statements.
  • The efficiency story — a concrete look at how model compression changes deployment.

How the API works

The friendly one-liner is the text-classification pipeline:

import { pipeline } from "@huggingface/transformers";

const clf = await pipeline("text-classification", "Xenova/mobilebert-uncased-mnli", { dtype: "int8" });
const out = await clf("The sky is clear. It is a sunny day.", { topk: 3 });
// [{label:"entailment", score:0.99}, {label:"neutral",…}, {label:"contradiction",…}]

The premise + hypothesis are concatenated into one input; the model classifies the pair. Everything runs in a Web Worker off the main thread.
