The productive pattern: you write the docstring (the spec), CodeGen writes the body (the code). Pick a utility below and get an implementation — the kind of private, offline scaffolding a developer tools startup could ship as a local autocomplete or boilerplate generator.

The model sees only the signature + docstring you selected, then writes the implementation. It's a draft — review like you would any generated code.
