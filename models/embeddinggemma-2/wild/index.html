Wild: text finds images, and images find text — one 768-d space, both directions

Most embedding models read text alone. EmbeddingGemma 2 pairs its 270M text backbone with a 170M vision encoder that projects photographs directly into the same 768-dimensional space. That means a text query can rank images by visual meaning, and a photograph can rank text passages without an intermediate captioning or translation step. Pick a search direction below, search the photograph library with text, or rank passages using an image. Both directions run below directly in your browser over WebGPU.

What this costs: the vision encoder is a separate 109 MB graph (bringing total q4 download to 284 MB), images are tokenized at ~280 soft tokens each, and video frames go through the same encoder at ~140 tokens per frame. Both modalities share the 8192-token context window.
