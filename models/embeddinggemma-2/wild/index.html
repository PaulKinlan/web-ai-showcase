Wild: How far past 2048 does it actually go?

EmbeddingGemma 1 had a verified limit of 2048 tokens. For EmbeddingGemma 2, the model card documents an 8K-token context window (with a 1024-token sliding window), while the exported ONNX configuration specifies a maximum position range of 262,144 tokens. Rather than quoting documentation claims, this page measures actual runtime retrieval on your own hardware: a distinctive authorization phrase is planted deep in a long document past token position 2048, and we measure whether the fact is retrievable from the full embedding versus a 2048-token truncation of the identical document.

Distinctive fact: The transfer authorisation phrase for the Vantage annex is KESTREL-7729-QUARTZ. Position 8 places it in Section 8 (beyond the 2048-token boundary). Lower slider stops move it earlier in the text.

Context documentation vs. export configuration: The EmbeddingGemma 2 model card documents an 8K-token context window with a 1024-token sliding window. However, the published ONNX export configuration (config.json) specifies text_config.max_position_embeddings of 262,144 tokens with a 512 sliding window, and the tokenizer sets no hard limit. Because documentation and artifact configuration diverge, this page quotes neither as a hard limit: it embeds your text directly on WebGPU and reports what the runtime actually processes.
