Wild: cross-lingual retrieval without translation

Because EmbeddingGemma 2 is multilingual across 100+ languages, it maps meaning into a single shared 768-dimensional vector space regardless of the input language. A search query written in one language can retrieve passages written in another by semantic meaning alone—with no machine translation step and no per-language indices. Search the mixed-language corpus below to measure cross-lingual cosine alignment directly on WebGPU.

Task instruction prefixes: Embedding the same text under different task instruction prefixes (query, document, classification, clustering) is separately demonstrated on the Basics page; this page uses the standard retrieval pair (query prefix for the query, document prefix for each passage) and does not re-demonstrate prefix variations.

Context provenance: The EmbeddingGemma 2 model card documents an 8K-token context window (1024-token sliding window), while the exported ONNX configuration specifies a maximum position range of 262,144 tokens. This page demonstrates bounded short passages (~20–30 tokens each) to measure cross-lingual retrieval within a bounded token budget, and does not claim to exercise long-context capacity.

Limitation: Upstream repository exports include separate vision and audio graph checkpoints; unproven image inference is not loaded or exercised here.
