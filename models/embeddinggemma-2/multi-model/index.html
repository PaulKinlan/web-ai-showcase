Why selective staging matters

In standard multimodal deployments, supporting visual search forces clients to download a single monolithic model encompassing every modality up front, even when users predominantly submit text queries. EmbeddingGemma 2 decouples the 270M text backbone (175 MB in q4) from the 170M vision encoder (109 MB in q4) and 300M audio encoder (189 MB in q4).

Because both encoders project vectors into the identical 768-dimensional L2-normalized vector space, the corpus index built by the text encoder is immediately searchable by image vectors. When visual search is triggered, the browser downloads only the 109 MB vision graph. The text index does not change — only the query's modality does — providing full cross-modal retrieval while paying the vision download price strictly on demand.
