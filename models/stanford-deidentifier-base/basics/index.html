What you're seeing

Each highlighted span is a run of tokens the model agrees are one piece of protected health information. The model is trained on radiology reports and medical notes, so it is tuned for exactly this register of text — abbreviations, section headers, template sentences. It is not a perfect identifier: real-world use always pairs it with a human check (the practical page shows the redaction workflow).

  • Patient — names of the patient (“Maria Gonzalez”, “Mr. John Okafor”).
  • Healthcare worker — names and titles of clinicians (“Dr. Perez”).
  • Hospital — institutions (“UH Medical Center”, “Mercy General”).
  • Date — dates in any common format (“1/1/2020”, “March 1st, 2019”).
  • ID — record numbers (“MRN 884102”, “ID 5874233”).
  • Phone — phone/fax numbers (“567-493-1234”).
  • Vendor — product/system names (“MedClinical data transmitter”).
