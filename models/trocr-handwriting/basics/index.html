Basics: strokes in, text out

The whole trick in one interaction: you write a line by hand, the model reads it. Two ways to try it — your own writing on the pad, and a real handwritten manuscript line.

1 · Write a word, watch it get read

Write a short word or name on the pad — print letters or cursive, your choice.

2 · Read a real manuscript line

A genuine handwritten manuscript page (public domain). Drag a box around one line — including the crossed-out words if you want to see how the model handles edits — and read it.

Drag to select a single line.

Honest limit: the model was trained on clean single lines. Crossed-out words and cramped double-spaced cursive are exactly where it stumbles — try a clean line vs. an edited one.
