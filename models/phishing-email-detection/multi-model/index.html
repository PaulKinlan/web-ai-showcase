Why this is the interesting part

A classifier and a summarizer are each useful alone. Chained, they're a template for a whole class of tool: an assistant that filters hostile mail and hands you a briefing, a security-ops queue that drops the lures and summarizes the genuine reports, a comment moderator that recaps only the legitimate feedback. The gate matters — feeding attacks into a summarizer wastes compute and pollutes the digest, so classify first, summarize second. Both models run locally, no server, no API bill.
