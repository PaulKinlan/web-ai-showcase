Phishing email detector — is this message trying to rob you?

A DistilBERT classifier fine-tuned to tell phishing emails and malicious URLs from legitimate ones. Paste any email or link and it scores it PHISHING or LEGITIMATE with a confidence — then look inside to see which exact words tripped the alarm. Everything runs on your device; the message never leaves the page.

See inside — the words that trip the alarm

This is occlusion attribution: we re-run the model with each word removed and see how much the phishing score shifts (measured in log-odds, because the model is so confident that raw percentages barely move). Remove a word that was pushing "phishing" and the score drops — so that word gets a red weight. Remove a word that was keeping it looking legitimate and the score rises — green. No gradients, no hand-waving: just the model's own predictions, N+1 of them.

pushes PHISHING pushes legitimate brighter = larger effect

Why it matters

Phishing is the single most common way breaches start — and the lures arrive by email, SMS, and chat faster than any blocklist can follow. Running the detector in the browser means a suspicious message can be scored the moment it is read, with its contents never leaving the device: no round-trip, no logging of the very credentials the attacker wants.

  • Read-side email defense — score a suspicious message inside the mail client or webmail, before anyone clicks.
  • Security-ops triage — batch-sort a reported-phish queue so analysts start with the highest-confidence catches.
  • SMS / chat scam filters — flag credential lures in messaging apps, offline and on-device.
  • Security training — show people which words (urgency, verification, look-alike links) make a message smell phishy.

How the API works

Classification is one call; top_k: 4 returns every class score:

import { pipeline } from "@huggingface/transformers";

const classify = await pipeline(
  "text-classification",
  "onnx-community/phishing-email-detection-distilbert_v2.4.1-ONNX",
); // downloads + caches ~64 MB once

const out = await classify("URGENT: verify your password now", { top_k: 4 });
// → [{ label: "LABEL_1", score: 0.9999 }, …]
// Card mapping: LABEL_0 legitimate_email · LABEL_1 phishing ·
//               LABEL_2 legitimate_url · LABEL_3 phishing_url_alt

"See inside" re-uses that same call: it classifies the full message plus one copy per word with that word deleted (batched in a single pass), then subtracts the threat log-odds to attribute the shift to each word. All of it runs in a Web Worker so typing never janks.
