llama2.c-stories15M — the smallest storyteller

This is a 15-million-parameter Llama, trained from scratch by Karpathy's llama2.c project on TinyStories — a dataset of short, simple tales written for 3–4 year olds. Fifteen megabytes of weights, yet it learned grammar, plot, and a happy ending. Give it an opener and watch it write, token by token, on your device.

Why it matters

The TinyStories line of work — and llama2.c — proved that scale isn't the only path to competence: a 15M model trained on a small, clean, constrained corpus can write coherent, grammatical stories. For the web, that means a language model that downloads in a second and runs on a five-year-old phone.

  • On-device everywhere — 15 MB loads instantly and runs on WASM with no GPU; perfect for low-end and offline-first products.
  • A teaching model — inspect every token, watch sampling work, understand the loop — with no 100 GB training run in sight.
  • Kids' content generators — bedtime-story drafts, reading-practice text, or fill-in-the-blank story games, all private and local.
  • A legible baseline — the smallest member of the Llama family to compare against bigger models on the same prompt.

How the API works

The friendly one-liner is the text-generation pipeline:

import { pipeline } from "@huggingface/transformers";

const gen = await pipeline("text-generation", "Xenova/llama2.c-stories15M", { dtype: "int8" });
const out = await gen("Once upon a time, there was a little fox named Fred who", {
  max_new_tokens: 90, do_sample: true, temperature: 0.8,
});
// out[0].generated_text → the opener plus a short children's story

The demo streams tokens through a TextStreamer inside a Web Worker, so the page never blocks — the token chain above is literally the stream, one real token at a time.
