CodeGen-350M — code autocomplete, fully offline

CodeGen, from Salesforce, was one of the first open models trained specifically to write code. This 350M version is the smallest: give it a function signature and docstring, and it writes the body — left to right, token by token, entirely on your device. No telemetry, no cloud, no network needed once cached.

Why it matters

CodeGen proved that a focused, code-only model could autocomplete real programs. Today that idea is everywhere — but a 350M version still runs on a plain CPU in a browser tab, which means code completion and generation with zero cloud round-trips.

  • Offline IDE autocomplete — a completion engine that works on a plane, on an intranet, or in a sandboxed iframe.
  • Spec → implementation — write the docstring, let the model write the body; great for scaffolding boilerplate.
  • Private code practice — a teaching tool that never uploads a learner's code anywhere.
  • Baseline for the family — CodeGen-350M is the smallest of Salesforce's three sizes; compare it against the bigger code models on the showcase.

How the API works

The friendly one-liner is the text-generation pipeline:

import { pipeline } from "@huggingface/transformers";

const gen = await pipeline("text-generation", "Xenova/codegen-350M-multi", { dtype: "q8" });
const out = await gen(
  'def fibonacci(n):\n    """Return the first n numbers of the Fibonacci sequence."""',
  { max_new_tokens: 80, do_sample: true, temperature: 0.7 },
);
// out[0].generated_text → the signature plus CodeGen's implementation

The demo streams tokens through a TextStreamer inside a Web Worker, so the page never blocks — the token chain above is literally the stream, one real token at a time.
