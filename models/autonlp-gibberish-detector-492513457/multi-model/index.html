Only analyse sentiment after an inspectable coherence gate

Stage one runs the canonical gibberish detector. If your visible policy accepts the text, stage two runs a pinned SST-2 sentiment model. If the gate stops, the sentiment worker does not infer and the page says so.

This composition narrows work; it does not prove safety

Both models are English-domain classifiers with distinct training data and failure modes. A stopped input may still be meaningful; an accepted input may still be spam, abusive, fraudulent, or unsafe. Never use this pipeline as a universal moderation or account-access decision.

  1. Stage one always returns real four-way scores from madhurjindal/autonlp-Gibberish-Detector-492513457@76672dd7….
  2. The user-set threshold and optional mild-score aggregation decide whether stage two receives the input.
  3. Stage two is real Xenova/distilbert-base-uncased-finetuned-sst-2-english@0b6928e… q8 inference—not a sentiment word list or canned result.
  4. Each model has independent shared cache, progress, retry, clear, release, and re-initialisation controls.
