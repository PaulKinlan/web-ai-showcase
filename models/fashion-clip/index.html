FashionCLIP — apparel concepts, ranked on your device

A fashion-specialised CLIP model turns a product image and your English labels into comparable 512-number vectors. It runs entirely in a Web Worker: no image upload, no fixed taxonomy and no canned result.

Why it matters

  • Editable taxonomies: change labels without retraining a classifier.
  • Private visual search: image and vocabulary stay local.
  • Domain-specific probes: colours, materials, styles and merchandising language can be compared in one space.

Scores are relative similarities, not calibrated facts. The model card warns about gender associations, English-only text, long-caption sensitivity and reduced reliability outside standard product photography.

How the API works

const rank = await pipeline(
  "zero-shot-image-classification",
  "patrickjohncyh/fashion-clip",
  { revision: "7e3ba62ce16b379a1ab479346b66f192e76f51b7", dtype: "fp32", device: "wasm" },
);
const scores = await rank(imageURL, ["white sneaker", "sports t-shirt"]);

This family goes one level lower—reusing the pipeline processor, tokenizer and model—to expose real projection tensors, cosines and logits from the same forward pass. Heavy preprocessing and inference stay in the worker.
