RoBERTa — predict the missing English word

RoBERTa is the canonical “BERT, trained properly”: the same 12-layer encoder, but trained ten times longer on 160 GB of English. Its one job here is masked language modelling: hide a word behind <mask> and it ranks what belongs there. Type a sentence with a mask and see its guesses, plus the exact logits it computed. Everything runs on your device.

See inside — logits, not just a guess

A language model doesn't output words — it outputs a logit (a raw, unbounded score) for every one of its 50,265 vocabulary tokens at the masked position. We softmax those into probabilities. The bars above show the probability; the logit beside each is the actual number the network produced. Watch how a confident prediction ("Paris") sits far above the pack in logit space, while an ambiguous slot spreads the mass out. The entropy below is computed over the shown top-k — low means RoBERTa is sure, high means it's hedging.

Why it matters

RoBERTa is the reference English encoder: it reads context well enough that its masked-word distribution is a usable probability model of English. Because it scores every word in context, you can ask it what fits, how strongly, and compare alternatives — all locally, with no prompt engineering and no API bill.

  • Offline autocomplete — suggest the next or missing word in a compose box, with real probabilities.
  • Cloze & vocabulary drills — generate fill-in-the-blank exercises with graded difficulty from the entropy.
  • Word-choice comparison — score candidate words at a slot (tone, register, formality) using the logits.
  • A teaching surface — the exact logits make “how a language model decides” legible without the maths.

How the API works

The one-liner uses the fill-mask pipeline:

import { pipeline } from "@huggingface/transformers";

const unmask = await pipeline("fill-mask", "Xenova/roberta-base");
const out = await unmask("The capital of France is <mask>.");
// → [{ token_str: " Paris", score: 0.83, sequence: "…" }, { token_str: " Lyon", … }]

For the "see inside" surface we go one level lower — AutoModelForMaskedLM — so we can read the exact logits tensor ([1, sequence, 50265]), slice the row at the <mask> position, and softmax it ourselves. That's the only way to show the real logit values, not just the pipeline's rounded scores. All of it runs in a Web Worker so the page never janks.
