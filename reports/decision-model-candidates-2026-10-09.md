# Decision-model candidates: browser feasibility (research snapshot)

- Checked: 2026-10-09; task: `web-ai-showcase-crn` (inventory only; demo work is `web-ai-showcase-4ti`).
- Scope: Hugging Face `decision-model` tag, named families from the task, current cards and `/api/models/<id>?blobs=true` file listings. See [machine-readable snapshot](decision-model-candidates-2026-10-09.json).
- **Status: NO locally verified browser-runnable candidate yet.** No Chrome launch, model download, inference, local latency or memory measurement was made. Publisher benchmarks below are explicitly not our results. This document is not an acceptance record and does not unblock a published demo.

## Discovery method and limits

The HF list endpoint `https://huggingface.co/api/models?filter=decision-model&limit=100` returns tagged entries. `filter=other:decision-model` returns none; `filter=decision-model&filter=transformers.js` returned 21 entries, not 21 browser-proven models. The latter includes GGUF entries and custom model types. Query every candidate's `https://huggingface.co/api/models/<org>/<repo>?blobs=true` for actual file sizes; a tag or an ONNX/GGUF blob is not proof that the repository's decision head, preprocessing and output decoding run in a browser. Current `scripts/inventory.mjs` filters on a recognized `pipeline_tag`, so it would omit `onnx-community/d1-omni-600M-ONNX` (`pipeline_tag:null`) unless explicitly inventoried.

## Named-family negative or unproven list

Canonical [LiquidAI/d1-omni-600M](https://huggingface.co/LiquidAI/d1-omni-600M/tree/02b55d7076f15129e59ab3f94783f32c4b088674) (2,348,774,500 B safetensors) and [LiquidAI/d1-3B](https://huggingface.co/LiquidAI/d1-3B/tree/051bcc464b01b9f92942b364d9586b0ef5912432) (6,247,065,504 B) have zero ONNX in **those canonical repositories** and require Python `trust_remote_code`/custom decision code; GGUF mirrors exist, but GGUF alone is not a browser runtime. The separately published d1 ONNX export above remains unverified and is not ruled out.

[Cloudflare/clef-flash](https://huggingface.co/Cloudflare/clef-flash/tree/fde727a287004204b7518dcc983fe64379776712) (four backbone safetensors shards totaling ~18.8 GB plus 243,538,016 B `joint_head.safetensors`) and [Cloudflare/clef](https://huggingface.co/Cloudflare/clef/tree/ed3eed331870db2eff4b0db01237128ede8a00ce) (12 shards, ~53 GB plus 256,125,024 B head) have no ONNX in the canonical repos; their [`joint_schema_model.py`](https://huggingface.co/Cloudflare/clef-flash/blob/fde727a287004204b7518dcc983fe64379776712/joint_schema_model.py) Python inference code runs a custom joint head, not a WebLLM token-generation model. Apache-2.0 does not resolve browser compatibility.

[internlm/Intern-Decision-4B](https://huggingface.co/internlm/Intern-Decision-4B/tree/0e5e6aa7d6d750e2b1504ba11a8136cb58aeb3cd) (language shards ~8.4 GB plus vision and projector), [openjev/openjev](https://huggingface.co/openjev/openjev/tree/ac97900fd034fdd7e7e536f3d4c21b836cae0750) (12 backbone shards ~53 GB, **CC-BY-NC-4.0** model weights despite Apache-licensed helper code), and [perplexity-ai/pplx-decider-v1.1-27b](https://huggingface.co/perplexity-ai/pplx-decider-v1.1-27b/tree/5cd25e3f8ae59ba65d1ebea74d8a06fa4a5f60fd) (~49 GiB BF16 weights plus custom readout) each have zero ONNX in their canonical repos and require model-specific Python/PyTorch or CUDA inference. Neither a canonical card's `pipeline_tag` nor serving via hosted API qualifies as local browser inference. Some differently named mirrors (including OneJev) exist and must be evaluated separately, not conflated.

**Negative scope:** zero ONNX in one repository does *not* prove all exports absent across HF. No universal claim of browser impossibility is made. A genuine new export with a compatible decision head and preprocessing can change the result.
